# Skills

Cada subdiretório representa uma capacidade específica da BOTina e deve conter um
arquivo `SKILL.md` com instruções operacionais.

Scripts exclusivos de uma capacidade devem permanecer dentro da própria skill.
Ferramentas compartilhadas por várias skills pertencem a `scripts/`.

Capacidades disponíveis incluem Cloudflare, Forward Email, Omie, Todoist, Notion,
Gmail, Calendar, Drive, Contacts e contas digitais da CPFL.

Exemplos de capacidades futuras:

- organização e catalogação de arquivos;
- agenda;
- e-mails e contatos;
- pesquisa na internet;
- elaboração de documentos;
- integração com sistemas externos.
